# 3D Character Interaction Architecture

This component adapts the 3D character interaction architecture, mouse/touch tracking, and animation utilities from:

**Repository:** [Shoaib Ahmed 3D Portfolio](https://github.com/ShoaibAhmedSoomro/Shoaib-Ahmed-3D-Portfolio)  
**License:** MIT License — Copyright (c) 2025 Moncy Yohannan

### Modifications:
- Adapted for Next.js 16 App Router.
- Styled with warm studio lighting and soft contact shadows for the warm ivory aesthetic (`#FAF8F5`).
- Integrated visitor-aware cursor settling, semantic CTA triggers (`[data-char-action]`), and clean WebGL resource lifecycle.
